World news of Wednesday, 25 November 2026 in one image: six stories that defined the day — Shenzhou-24 launches for Tiangong, Ukraine's drone strike on a Russian ship in the Gulf of Finland, a Russian warship sunk off Libya, the Houthi strike on Riyadh's tallest tower, Baghdad's move to take over Kurdish oilfields, and Sarkozy ordered to trial plus Real Madrid's 5–1 win over PSV.

The image is rendered by `generate_image.py` (Pillow, Liberation Sans) into `entry.png`, stored in the repository as base64 text in `entry.png.b64`, and `main.ts` (Node 22, standard library only) decodes it to `/output/entry.png`. The program runs with no network and produces byte-identical output on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
